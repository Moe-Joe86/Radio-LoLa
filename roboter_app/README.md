# Radio LoLa

Radio für den Reachy Mini Wireless. Die rechte Antenne des Roboters (von vorn gesehen links) sucht Sender,
die linke stellt die Lautstärke; zwischen den Sendern rauscht es. Sender und Grenzwerte stehen in
`radio_lola/einstellungen.toml`.

Quelle und Anleitung: https://github.com/Moe-Joe86/Radio-LoLa
