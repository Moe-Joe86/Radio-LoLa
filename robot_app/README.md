# Radio LoLa

A radio for Reachy Mini Wireless. The robot's right antenna (on the left seen from the front) tunes stations, the
left one sets the volume, with noise between the stations. A small Android app starts and stops the radio, picks
stations, sets the volume and manages the station list.

Source, installation and the Android app: https://github.com/Moe-Joe86/Radio-LoLa
